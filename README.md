# 💌 Болзоонд урих веб апп (Date Invitation Web)

Харилцагч буй бүсгүйгээ болзоонд урих, хариултыг нь цаг хугацаатай нь шууд өөрийн **Google Spreadsheet** рүү хүлээн авах зориулалттай романтик, интерактив веб апп.

Энэхүү төсөл нь тусдаа backend сервер ажиллуулах шаардлагагүй бөгөөд **GitHub руу push хийгээд Vercel дээр 1 минутанд шууд байршуулах (deploy хийх)** бүрэн боломжтой.

---

## ✨ Онцлог боломжууд

1. **Хөгжилтэй & Эгдүүтэй UI/UX**:
   - "Үгүй" гэж дарах гэж оролдоход товч зугтаж, үг нь өөрчлөгдөнө.
   - Зэрэгцээд "Тэгье!" товч улам томорч, анхаарал татна.
   - "Тэгье!" дээр дармагц конфетти цацагдаж, дараагийн алхам руу шилжинэ.

2. **Болзооны дэлгэрэнгүй төлөвлөгөө сонголт**:
   - 🗓️ **Хэзээ**: Амралтын өдөр, тусгай өдөр товлох календарь
   - ⏰ **Цаг**: Өдрийн болзоо, үдшийн зоог, шөнийн хот харах
   - 🍝 **Хоол**: Итали хоол, Суши, Стейк & Дарс, Кофе & Амттан, Солонгос BBQ, "Намайг гайхшруулаарай"
   - 🎡 **Хийх зүйл**: Алхалт, Кино, Arcade/Боулинг, Үзэсгэлэн, Шөнийн drive
   - 🎵 **Нэр & Дууны хүсэлт**: Хүсэлтээ бичих талбар

3. **Google Sheets интеграци**:
   - Бөглөж илгээсэн даруйд Улаанбаатарын цагаар **он, сар, өдөр, цаг, минут, секундийн хамт** шинэ мөр болон таны Google Sheet дээр бодит цагт орж ирнэ.

4. **Баталгаажуулах "Date Ticket"**:
   - Амжилттай бөглөсний дараа нислэг / болзооны тасалбар маягийн гоёмсог хуудас харагдаж, дурсгал болгон үлдэнэ.

5. **Хөнгөн & Хурдан (Zero Backend)**:
   - Backend сервер бэлдэх, төлбөртэй сан ашиглах огт шаардлагагүй.
   - Vercel дээр 0 секундэд шууд ажиллана.

---

## 🚀 3 алхамт хурдан тохиргоо

### Алхам 1: Google Sheet бэлдэх (1 минут)

1. [sheets.new](https://sheets.new) хаягаар орж шинэ Google Sheet үүсгэнэ.
2. Дээд талын цэснээс **Extensions (Өргөтгөлүүд)** ➔ **Apps Script** дээр дарна.
3. Нээгдэх цонхонд байгаа кодыг арилгаад, энэхүү төслийн `google-sheet-script.js` файлын доторх кодыг хуулж тавина.
4. Баруун дээд талын **Deploy** ➔ **New deployment** товчийг дарна:
   - **Select type** (араа дүрс): `Web app`
   - **Description**: `Date Invite`
   - **Execute as**: `Me`
   - **Who has access**: `Anyone` *(Маш чухал: Хэн ч бөглөх боломжтой болгохын тулд "Anyone"-ийг сонгоно)*
5. **Deploy** товч дарж, эрх олгоно (`Authorize access` ➔ `Advanced` ➔ `Go to Untitled project (unsafe)` ➔ `Allow`).
6. Гарч ирсэн **Web app URL**-ийг хуулж авна.

### Алхам 2: Төсөлдөө URL-ээ холбох (30 секунд)

`config.js` файлыг нээгээд `GOOGLE_SCRIPT_URL` хэсэгт хуулсан URL-ээ тавина:

```javascript
window.CONFIG = {
  GOOGLE_SCRIPT_URL: "https://script.google.com/macros/s/таны_авсан_код/exec",
  inviterName: "Миний нэр",
  defaultCrushName: "Хөөрхнөө"
};
```

*(Хүсвэл нэр, текстийг өөрийн хүссэнээрээ өөрчилж болно)*

### Алхам 3: GitHub руу push хийж, Vercel дээр байршуулах (1.5 минут)

#### GitHub руу оруулах:
```bash
git init
git add .
git commit -m "feat: romantic date invitation web app"
git branch -M main
git remote add origin https://github.com/таны-хэрэглэгчийн-нэр/date-invite.git
git push -u origin main
```

#### Vercel дээр тавих:
1. [vercel.com](https://vercel.com) руу өөрийн GitHub эрхээр нэвтэрнэ.
2. **Add New...** ➔ **Project** дарна.
3. Дөнгөж үүсгэсэн `date-invite` репогоо сонгоод **Import** дарна.
4. Framework Preset эсвэл Build Command өөрчлөх шаардлагагүй (Other/Static автоматаар танигдана).
5. **Deploy** дарна!

🎉 **10 секундийн дараа таны веб бэлэн болж `https://таны-нэр.vercel.app` гэсэн линк үүснэ! Энэ линкээ харилцагч эмэгтэйдээ илгээхэд л хангалттай.**

## 📁 Төслийн бүтэц

```text
├── index.html              # Интерактив веб хуудас (Romantic UI, олон алхамт асуулга)
├── style.css               # Орчин үеийн романтик өнгө, хөдөлгөөнт анимэйшн, responsive дизайн
├── script.js               # Зугтдаг "Үгүй" товч, confetti, дуу, өгөгдөл илгээх логик
├── config.js               # Google Apps Script Webhook URL болон хувийн тохиргоо
├── google-sheet-script.js  # Google Sheet рүү хуулж тавих Apps Script код
├── vercel.json             # Vercel тохиргоо (Clean URLs & security headers)
├── package.json            # Төслийн мэдээлэл болон локал preview хийх скрипт
└── README.md               # Заавар ба мэдээлэл
```

## 📱 Локал орчинд шалгах

Компьютер дээрээ туршиж үзэхийг хүсвэл:
`index.html` файлыг дурын хөтөч дээрээ (Chrome, Edge, Safari) шууд давхар товшоод нээж үзэж болно.
Эсвэл:
```bash
npx serve .
```
гэж ажиллуулаад гарч ирсэн `http://localhost:3000` хаягаар орно.
